Files:
- groupmessage/User.java ..... The User class
- groupmessage/Logger.java ... The Logger class
- groupmessage/Group.java .... The Group class
- groupmessage/Exp1.java ..... The benchmark for RQ1
- groupmessage/Exp2.java ..... The benchmark for RQ2

NOTICE

As the SignalJ compiler does not support batch compilation, the above files
must be compiled separately in the order: User.java, Logger.java Group.java,
Exp1.java, and Exp2.java

Also, to run the benchmark programs, it is necessary to setup the databases
both for the data source and application environments. For the Artifact
Evaluation, we will provide containers for each data source and application
environments that are ready for running the benchmark programs.
